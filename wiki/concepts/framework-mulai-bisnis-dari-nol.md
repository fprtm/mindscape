# Framework Mulai Bisnis dari Nol

## Summary

Framework Theo Derick (Dig Deeper, 2024) yang tidak ada di buku: **Resources (skill, money, time, knowledge) + Koneksi (family → circle → komunitas) → Opportunities (di circumstances lu) → Connecting the Dot → Eksekusi minim efisien**. Contoh eksekusi: pameran 4 hari Grand Indonesia dari tabungan semester 7 + networking + opportunity kampus → jadi Kota Tua Market 2015.

## Details

Langkah konkret (dari `[[wiki/sources/2026-08-28-step-by-step-mulai-bisnis-dari-nol-dig-deeper]]`):

1. **Resources 4 kolom**
   - Skill (negotiating, networking), Money (tabungan r juta), Time (jam kosong/minggu), Knowledge (fashion, resep kue, dll) — tulis semua, jangan di kepala.
2. **Koneksi 3 lapis** (bukan uang mereka, tapi kerjaannya)
   - Inner: papa mama om tante → kerja apa? (pabrik gula, toko kue, kerupuk)
   - Wider: teman gereja/kuliah/kerja 5-10 nama + kerjaannya → ada entrepreneur besar karyawan 100?
   - Extended: papa mama mereka / pasangan → kerja apa?
   → jadi **bank database resources** yang sebelumnya tidak aware.
3. **Opportunities**: list peluang di circumstances sekarang — komunitas entrepreneur, family bisnis bangunan (pasir, bata, semen), AI, sosmed, bahkan `jual apapun mereka bisa bayar`.
4. **Connecting → Execution**: kawinkan, lalu mulai dari kondisi paling minim efisien. Theo: skill networking + tabungan + time fleksibel sem 8 + network Bisnis School + opportunity butuh nilai lulus → pameran. Validasi money/time/connection dulu sebelum eksekusi.

Catatan privilege: Theo background single parent, ordinary worker, kuliah Prasmul bagi dua dengan nyokap — framework ini sengaja dibikin tanpa asumsi privilege.
