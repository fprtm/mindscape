# What is a Modular Monolith? — GeeksforGeeks (System Design)

## Summary

GeeksforGeeks (101 lines, 2024-04-04) — modular monolith = gabungan monolithic (all-in-one) + modular (building block) — ambil benefit keduanya: single deploy tapi terstruktur modular, vs monolithic tightly integrated (UI+logic+data) deployed bareng.

## Details

- **Sumber**: `https://www.geeksforgeeks.org/system-design/what-is-a-modular-monolith/` (101 lines, clip 2026-08-29).
- **Inti**: monolithic = single indivisible unit (UI, business logic, data access tightly integrated), modular = building block, modular monolith = hybrid — single codebase/deploy tapi modul terpisah.
